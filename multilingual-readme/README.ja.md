# UCE Tool

[简体中文](README.zh-CN.md) | [English](README.en.md) | [Deutsch](README.de.md) | **日本語** | [Français](README.fr.md)

UCE Tool は USB-C Explorer 用のデスクトップアプリです。リアルタイム測定、E-Marker の読み取り、PD 検出・キャプチャ、デバイスのテーマ設定、ファームウェア更新に対応しています。

## インストールと接続

[リリースページ](https://github.com/Asuka-019/UCE-Tool/releases/latest)から Windows または macOS 用のパッケージをダウンロードしてください。Windows では展開してアプリを起動し、Mac ではアプリを「アプリケーション」フォルダにインストールします。

データ通信に対応した USB ケーブルでデバイスをパソコンに接続します。左側に表示されたデバイスカードをクリックすると接続します。接続中のカードをもう一度クリックすると切断し、別のカードをクリックすると接続先を切り替えます。デバイスは自動検索されますが、自動接続はされません。

## ダッシュボード

**ダッシュボード**を開き、開始アイコンを押すと測定値とグラフを表示します。表示する曲線、サンプリングレート、時間範囲を変更でき、グラフの一時停止や消去もできます。

## E-Marker

デバイスの端子表示に従ってケーブルを接続し、**E-Marker** を開きます。**読み取り**でケーブル情報を取得できます。連続問い合わせは同じボタンでもう一度押すと停止します。連続問い合わせの前に、アプリの注意に従ってデバイス出力から受電機器を外してください。

**検出履歴**では今回の結果を確認し、Excel にエクスポート、または消去できます。デバイスから報告されない項目や識別できない項目は「不明」と表示されます。

## PD 検出

検査する充電器を接続し、**PD 検出**を開きます。検出開始ボタンを押し、警告を確認してください。各 PDO と検出結果が表示されます。検出中は同じボタンで停止できます。検出履歴は表示、Excel へのエクスポート、消去が可能です。

**検出中は電圧が上昇することがあります。開始前にデバイス出力から受電機器を外してください。**

## PD アナライザー

デバイスの端子表示に従って測定対象を接続し、**PD アナライザー**を開きます。キャプチャ開始ボタンを押し、停止するときは同じボタンを押します。報文を選択すると、下部にヘッダーとデータオブジェクトが表示されます。上下の境界線をドラッグすると表示領域を調整できます。

CRC ボタンで GoodCRC 報文の表示・非表示を切り替えます。Excel エクスポートには非表示の GoodCRC も含まれます。

**Excel をインポート**すると、分析画面からエクスポートした記録を再表示できます。先にキャプチャを停止してください。インポートすると現在の一覧は置き換わります。

## テーマ設定

矢印でデバイス画面を切り替え、プレビューの色領域または背景色をクリックして変更します。

- **既定に戻す**：既定の配色に戻します。
- **デバイスから読み取る**：現在の配色を取得します。
- **デバイスに適用**：配色を一時的に適用します。
- **デバイスに保存**：再起動後も配色を保持します。

## ファームウェアと設定

**ファームウェア更新**を開き、バージョン一覧を取得して、デバイスに合ったファームウェアを選択します。画面の案内に従い、完了まで接続と電源を維持してください。

設定では言語やデバイス情報を確認でき、サイドバーからライト／ダークモードを切り替えられます。記録は今回の実行中のみ保持されるため、必要なものは終了前にエクスポートしてください。デバイスが使用中の場合は、他の検出やキャプチャを停止してください。

## 詳しい使い方

### 起動とデバイス接続

通常、Windows と macOS のアプリ版を使うために Python を別途インストールする必要はありません。Mac では Apple Silicon または Intel に合うパッケージを選んでください。初回起動を macOS がブロックした場合は、入手元を確認したうえで「システム設定 → プライバシーとセキュリティ」で許可します。

デバイスのデータ通信用端子をパソコンにつないでください。充電専用ケーブルでは給電できても通信できないことがあります。サイドバーにはデバイス名、短縮されたシリアル番号、APP バージョンが表示され、完全なシリアル番号はデバイス情報で確認できます。BOOT モードではファームウェアの復旧が可能ですが、測定や検出にはアプリケーションファームウェアが必要です。

### ダッシュボードの見方

VBUS は電圧、IBUS は電流、POWER は電力を表します。D+ / D− と CC1 / CC2 は各信号線の電圧です。電圧・電流・電力のグラフはそれぞれ別の目盛りを使用するため、比較するときは単位を確認してください。グラフにポインターを合わせると測定値を確認でき、`--` はその位置に値がないことを示します。

サンプリングレートは毎秒 1・10・50 回、表示時間は 10・30・60・120 秒から選べます。一時停止中は表示が保持され、再開すると測定を続けます。消去すると表示中の履歴が削除されます。

### E-Marker と PD の結果

表示できる E-Marker 情報はケーブルとファームウェアによって異なります。線種、定格電流、最大電圧、データ速度、PD バージョン、TBT、EPR、長さまたは遅延などを確認できます。遅延から推定した長さは実測値ではありません。E-Marker の生データはケーブル情報の下に表示されます。

PD 検出では充電器が通知した PDO を読み取り、ファームウェアが個別の検査状態を返した場合はその結果も表示します。PDO が通知されたことだけで、その検査に合格したとは限りません。結果上部のタブで結果と履歴を切り替えられます。必要な機能が未対応の場合は対応するデバイスファームウェアに更新してください。

E-Marker と PD 検出の履歴は今回の実行中の記録です。履歴を消去すると現在の一覧が削除されます。Excel エクスポートでは `.xlsx` ファイルが作成されるため、必要な結果は終了前に保存してください。

### PD キャプチャの見方

一覧には報文種別、SOP チャネル、メッセージ ID、方向、オブジェクト数、PD リビジョン、経過時間、電圧・電流の測定値、生データ、注記などが表示されます。行を選択すると、下にメッセージヘッダーと解析可能なデータオブジェクトが表示されます。項目が多い場合は詳細領域を上下左右にスクロールできます。

Attach と Detach は接続状態のイベント、Hard Reset は監視対象の PD 接続上のリセットイベントです。意味を確実に判断できないフィールドは生の値で表示されることがあります。ケーブル報文の送信元を特定できない場合、方向はポートとプラグ間の通信として表示されます。

GoodCRC の非表示は画面表示だけに影響し、Excel には非表示の報文も含まれます。

### 配色とファームウェア

テーマの色はまずプレビュー上で変更します。**デバイスに適用**で一時的に確認し、電源を切った後も保持したい場合は **デバイスに保存**を使用してください。**デバイスから読み取る**とプレビューが現在のデバイス配色に置き換わり、**既定に戻す**と編集内容が既定値に戻ります。

ファームウェア更新ではバージョン一覧を取得し、デバイスに対応したパッケージを選択して、進行状況と結果を確認してください。更新中は電源やデータケーブルを外さないでください。UCE Tool 自体の更新は別の操作で、「バージョン情報」メニューから行います。

### 困ったとき

- **デバイスが表示されない**：電源、データケーブル、端子を確認して接続し直してください。カードが表示されたらクリックして接続します。
- **デバイスが使用中**：他の E-Marker 問い合わせ、PD 検出、キャプチャ、更新を停止し、終了を待ってください。
- **E-Marker の結果がない**：ケーブルと接続を確認してください。すべてのケーブルに E-Marker があるわけではなく、一部の情報が返らない場合もあります。
- **報文が表示されない**：デバイスの接続、キャプチャの開始、測定端子を確認し、GoodCRC の非表示設定も確認してください。
- **更新・エクスポートが失敗する**：表示されたエラー、空き容量、ファームウェアの選択、接続を確認して再試行してください。
